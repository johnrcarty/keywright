# 0.0.2 release validation

Published on 2026-11-07 from frozen commit
`cc5203bd3bcb8ff710ee0f89980203f3a872a630`. The tag and published package bytes
remain unchanged by subsequent documentation updates.

## Release evidence

- [Tagged CI and image publication](https://github.com/johnrcarty/keywright/actions/runs/42315069296):
  passed on Python 3.12–3.14, including PostgreSQL/pgvector tests, package builds,
  installed entry points, and topology JavaScript checks. The merged commit's
  Python 3.12 run recorded **1,364 tests passed** with no optional PostgreSQL skips.
- [Independent package validation](https://github.com/johnrcarty/keywright/actions/runs/42310709939):
  all six wheels/source archives passed identity, version, license and strict Twine
  checks, plus fresh wheel and source installations outside the checkout.
- [TestPyPI and production PyPI publication](https://github.com/johnrcarty/keywright/actions/runs/42315172599):
  all three packages uploaded and verified successfully on both indexes. Production
  environment approvals were submitted following the owner's publication instruction.
  The workflow verified complete index file sets and SHA-256 hashes, downloaded both
  archives per package, and tested fresh wheel/source installs with dependencies from PyPI.
- A separate anonymous PyPI download check matched all six files to the reviewed
  validation build byte-for-byte. The hashes below are the published bytes.
- AMD64 and ARM64 images passed standalone Compose tests and fresh published-image
  pulls. Corresponding-source images, inventories, notices and native dependency
  checks passed for both architectures.
- Anonymous registry access verified that stable tag `0.0.2` resolves to both architectures.
- [GitHub Release](https://github.com/johnrcarty/keywright/releases/tag/v0.0.2): public,
  with 14 checksummed assets plus SHA256SUMS. All draft asset bytes were checked,
  including both corresponding-source archives; public asset digests matched afterward.
  The installer, notes and checksum manifest were downloaded anonymously and verified.
  The installer contains the stable manifest digest below and all inner checksums passed.
- DoorDash remains explicitly Beta and waitlist-only, with the requested approved-account
  notice and waitlist URL in the UI and published release notes.
- All four Copilot findings were fixed before tagging. Focused regression checks:
  **127 passed** for input bounds, notification destinations, attaching existing
  repositories without losing locations, archived content visibility, and related behavior.
  Mobile attachment and DoorDash setup checks passed without horizontal overflow or
  JavaScript errors. These used synthetic data and performed no real purchase.

## Source and material review scope

Package payloads were compared with tracked source. Source archive identity matched
`git archive` of the frozen commit. Both architecture inventories passed the existing
reviewed dependency/source-lock checks, and downloaded notice/manifest checksums matched.
Five connector artwork/license files matched their recorded provenance hashes.

A bounded tracked-source screen checked private key blocks, GitHub/AWS token patterns,
known private host identifiers, and credential/database filenames. Matches were one
key-input placeholder and synthetic token test fixtures; no live credentials were
identified. Docker inputs remain allowlisted. These checks do not prove the absence
of every possible secret or replace a comprehensive security assessment.
